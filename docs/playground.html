Curve playground

This is the integration's real dashboard card — the same flare-curve-card.js that ships inside the integration and renders on your own dashboard, not a picture of it. Move any slider and the schedule is recomputed and handed back to the card exactly the way a live Home Assistant would.

Each bar is one five-minute slice of the day: its height is brightness and its colour is that moment's colour temperature, converted to RGB the same way the lights are told to render it. The vertical line is "now" — drag Time of day to move it.

Time of day

Moves the "now" marker. Nothing about the schedule changes — this is just where you're standing in the day.

Schedule

When each phase begins. Every one of these is a time entity on the schedule you add in Home Assistant — except sunset, which comes from sun.sun.

Brightness

Each phase's brightness. Evening's is a starting point rather than a hold: it fades toward Night's value over the run-up to Night Start.

Colour temperature

Each phase holds its own colour and eases to the next one over that phase's transition, below.

Transitions

How long before each phase ends to start easing toward the next one — so the new phase's values have arrived exactly as it begins. Set one to zero for a deliberate, visible change at that boundary. Anything longer than the phase it runs in simply covers the whole phase, which is why Day's colour transition defaults to a full day: it slides from Morning's colour to Evening's across the entire afternoon.

What the phases are for

The four phases aren't four points on one continuous sun-tracking curve — each exists for its own reason, which is why they're configured separately. There's more on the thinking behind that on the home page, and the full input-by-input reference in the blueprint reference.
